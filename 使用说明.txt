小白 2080 · 真正自由问答版

这是可运行的网页 + AI 服务端，不是只有关键词回复的静态页面。

1. 需要 Python 3 和 OpenAI API Key（API 按使用量计费，ChatGPT 订阅不等于 API 额度）。
2. macOS/Linux 终端：
   export OPENAI_API_KEY="你的密钥"
   export OPENAI_MODEL="你有权限使用的模型名"
   python3 server.py
3. Windows PowerShell：
   $env:OPENAI_API_KEY="你的密钥"
   $env:OPENAI_MODEL="你有权限使用的模型名"
   python server.py
4. 浏览器打开 http://localhost:8000

如模型 gpt-6 不在你的 API 账号可用列表，请将 OPENAI_MODEL 设置为实际可用的模型。
不要把 API Key 放到 index.html、公开仓库或发给别人。
在 iPad 上体验真正 AI 对话需要把服务端部署到带 HTTPS 的主机；仅打开 index.html 文件会进入明确标注的离线演示模式。
公开部署前应增加用户鉴权、限流、费用上限和日志隐私保护。

本次整理：统一小白对话与语音
- 学业领航、成长发展、情感陪伴和生活助手共用“与小白对话”入口；不同情境的对话只在本次页面中保留，刷新后清除，不自动读取私人日记。
- 录音需要 HTTPS（本地 localhost 也可）及浏览器麦克风权限。点击开始，再点击停止；需确认“转成文字”才上传录音，识别文字检查后再发送。
- 录音最长60秒，服务端上限8 MB；只在请求过程中处理，不写入音频文件。转写使用 OpenAI 音频服务。
- “用声音回答”默认关闭；可选择自然语音或设备朗读。自然语音是AI合成，可选择两种声音并随时停止。浏览器阻止自动播放时，点击“播放最新回复”。
- 复用现有 OPENAI_API_KEY。自然语音与转写会产生对应API费用；需账号具备音频模型权限。默认模型：gpt-4o-mini-transcribe、gpt-4o-mini-tts。可通过 OPENAI_TRANSCRIBE_MODEL、OPENAI_SPEECH_MODEL 覆盖。
- 积分、企业检索与饮食运动工具保留在可选折叠区；成长档案和真实实践结果为主线。
- 测试：python3 -m unittest discover -s tests -v。浏览器测试需要Playwright和Chromium，服务运行本身仍只使用Python标准库。
